# Web Design Guidelines & Engineering Standards

## UI/UX Rules
- Use strictly semantic component design via shadcn/ui.
- Maintain accessible color contrast (WCAG AA standards).
- Group interactive micro-animations with Framer Motion natively.

## Development Workflow
1. When asked for new UI, always use magic-mcp or shadcn registries first.
2. Draft a layout plan *before* executing component injection.
