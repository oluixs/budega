# Registros de erro

Cada subpasta `YYYY-MM-DD/` contém um arquivo por erro relevante. Veja o formato
obrigatório e o protocolo completo em `.audit/README.md`.

Antes de investigar um novo erro, procure por termos relacionados (nome de arquivo,
rota, componente, tabela, comando, mensagem) nos arquivos existentes aqui — é possível
que o mesmo problema (ou a causa raiz) já tenha sido documentado.
